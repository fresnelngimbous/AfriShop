# AfriShop

Site vitrine d'AfriShop, boutique de produits africains (mode, artisanat, produits locaux).

**Auteur :** Fresnel Ngimbous

**Technologies :** HTML5, CSS3 (Flexbox), Git, GitHub

## Lancement
1. Cloner le dépôt : `git clone https://github.com/fresnelngimbous/AfriShop.git`
2. Ouvrir le dossier AfriShop
3. Double-cliquer sur `index.html` pour l'ouvrir dans le navigateur
